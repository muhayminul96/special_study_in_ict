# Scikit-Learn Algorithms

###  Classification
* **Logistic Regression:** Linear classifier that estimates class probabilities using the sigmoid function.
* **Support Vector Classifier (SVC):** Maximizes margin boundaries between classes using kernel tricks for non-linear data.
* **K-Nearest Neighbors (KNN):** Classifies or regresses samples based on the majority vote or average of their $k$ closest neighbors.
* **Naive Bayes:** Fast probabilistic algorithm applying Bayes' theorem under strong feature independence assumptions.
* **Decision Tree:** Splits data recursively based on feature thresholds to create easy-to-interpret decision rules.

---

### Regression
* **Linear Regression:** Fits an ordinary least squares hyperplane to model continuous linear relationships.
* **Ridge / Lasso:** Linear regression with L2 (Ridge) to shrink coefficients or L1 (Lasso) to zero out irrelevant features.
* **Support Vector Regressor (SVR):** Fits continuous predictions within a defined margin tolerance boundary.

---

###  Ensemble Methods
* **Random Forest:** Bagging ensemble that averages predictions from multiple independent, parallel decision trees.
* **Gradient Boosting (GBDT / Hist):** Sequential boosting ensemble that iteratively builds trees to correct prior residual errors.

---

### Clustering & Unsupervised
* **K-Means:** Unsupervised algorithm partitioning data into $K$ spherical clusters around central centroids.
* **DBSCAN:** Density-based clusterer that finds arbitrary-shaped clusters and automatically isolates noise points.

---

### Dimensionality Reduction
* **PCA:** Unsupervised linear feature extractor that projects high-dimensional data onto axes of maximum variance.
